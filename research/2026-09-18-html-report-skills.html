分场景结论

场景选择理由
正式数据报告（评测 / 归因分析）huashu-data-pro交互式 HTML 报告默认输出；「数据不说谎」规范（Y 轴从 0 起、禁 CDN 依赖防离线截图白屏、颜色语义化）与既有报告规范同频。
幻灯片式逐页讲解的数据报告ppt-report-skills一页 3 小文件、Excel/CSV 数据与渲染分离，改数不重画图；9 模板 + 5 主题 + 一键 PDF。
对外汇报 / 分享演示guizang-ppt-skill单文件横向翻页 deck，演讲者模式与排练内置；线下投屏可配 html-to-ppt-pdf 转图片型 PDF 兜底。
调研类文档想拿公网链接pages-publish任意单文件 HTML 一键发布 GitHub Pages，多项目目录分组，URL 稳定可修订重发。
设计质量不满意时frontend-design + theme-factory官方设计规范与 10 套主题叠加使用。

本站目录设计（多项目管理）

站点采用「单仓库、URL 即分组」结构：每个项目一个目录，个人杂项进 misc；发布时自动重建按项目分组的索引页与 manifest.json 清单，同日同 slug 重发覆盖旧版，URL 保持稳定。

ligjn/reports（Pages 站点）
├── index.html          # 按项目分组的目录页（自动生成）
├── manifest.json       # 全量清单：project / file / title / date / description
├── research/           # 调研与实验
├── <project>/          # 各业务项目，一个项目一个目录
└── misc/               # 无项目归属的个人内容（默认分组）

安装方式

# 生成类：clone 进用户 skill 目录即可被 agent 识别
git clone --depth 1 https://github.com/op7418/guizang-ppt-skill ~/.agents/skills/guizang-ppt-skill
# huashu-data-pro 从 52-skill 集合中按需抽取（本文只装子集）
# pages-publish：自研，位于 ~/.agents/skills/pages-publish/
python3 ~/.agents/skills/pages-publish/scripts/pages_publish.py init --repo ligjn/reports --public
python3 ~/.agents/skills/pages-publish/scripts/pages_publish.py publish report.html "标题" --project research --slug my-report
已知限制：*.github.io 在国内网络访问可能不稳定；发布通道在 git 直连失败时会自动回退到 GitHub Contents API 直传（本页首次发布即走了该通道）。
